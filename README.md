# Sentinel Campus

Landing page for the **Intelligent Campus Cybersecurity Threat Detection System**.

Sentinel Campus is presented as a calm, human-centered security operations layer for modern campuses. The page communicates the product through a live operations dashboard, signal metrics, detection capabilities, and a three-step workflow.

## Run locally

This is a dependency-free static website. Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Structure

- `index.html` — semantic page structure and content
- `styles.css` — responsive visual system and dashboard illustration
- `script.js` — small progressive-enhancement interactions for workflow steps and reveal animations

## Deploy

The project can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider without a build step.
